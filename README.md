# 🚀 Developer Portfolio

A sleek, modern, and highly interactive digital portfolio designed to showcase projects, skills, and professional experience. Built with a focus on immersive UI elements, fast load times, and fluid animations.

## 🛠️ Tech Stack
- **Next.js & React** (App Router for optimized SSR & CSR)
- **TypeScript** (For robust, type-safe code)
- **Tailwind CSS v4** (For utility-first styling and glassmorphism)
- **Framer Motion** (For smooth scroll-reveals and micro-animations)
- **Lucide React** (For modern iconography)
